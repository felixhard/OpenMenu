# Code of conduct

OpenMenu welcomes people of all backgrounds and experience levels. This code of
conduct applies to issues, pull requests, reviews, and other project spaces.

- Treat others with respect and give feedback about the work.
- Make room for questions and different perspectives.
- Respect people's privacy and get consent before sharing their personal information.
- Harassment, discriminatory language, threats, and personal attacks are unacceptable.

## Reporting and moderation

Use GitHub's **Report content** option to report a concern privately. If that
option is unavailable, use the [GitHub abuse report form](https://support.github.com/contact/report-abuse).
Include a link to the relevant content and any context needed to understand what
happened. Maintainers may remove content, lock conversations, or restrict
participation to address violations.
