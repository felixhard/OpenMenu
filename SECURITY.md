# Security policy

OpenMenu is in pre-release development. Security fixes are made on `main`.
Include the commit SHA or app version you tested when you file a report.

## Report a vulnerability

Use [GitHub's private vulnerability form](https://github.com/felixhard/OpenMenu/security/advisories/new)
to share the affected feature, macOS version, steps to reproduce the issue, and
its impact. Use sample data and remove secrets, clipboard contents, private
paths, and other personal information from any attachments.

Keep the report private while a fix is being investigated. For regular bugs and
feature requests, use the [issue tracker](https://github.com/felixhard/OpenMenu/issues).
